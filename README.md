# NPDES Data Analysis w/ ArcGIS & Databricks: Effluent Violations in Three U.S. States

Summary: A portfolio project utilizing ArcGIS, Databricks, and public NPDES data to analyze trends in effluent violations across counties in three US states.

Research Question: In Pike, Orange, and Sussex counties, which NPDES-permitted facilities have repeated effluent violations, where are they, and do violations differ by state and why?
